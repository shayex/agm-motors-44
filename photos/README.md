# Dossier `photos/` — photos du bureau

Déposez ici les **photos des membres du bureau**.

- Format conseillé : image **carrée** (ex. 800×800 px), en `.jpg`.
- Le nom du fichier doit correspondre au champ `photo:` de la liste des
  membres dans `index.html` (repère « ▼▼▼ LES MEMBRES DU BUREAU ▼▼▼ »).

Noms attendus par défaut :

| Membre    | Fichier            |
|-----------|--------------------|
| Thomas L. | `thomas.jpg`       |
| Marion B. | `marion.jpg`       |
| Kévin D.  | `kevin.jpg`        |
| Sarah A.  | `sarah.jpg`        |
| Julien M. | `julien.jpg`       |
| Noé R.    | `noe.jpg`          |

Si un fichier est absent, les initiales du membre s'affichent à la place :
le site n'est jamais cassé.

### Comment déposer une photo ici

1. Ouvrez ce dossier `photos` sur GitHub.
2. Bouton **Add file → Upload files**.
3. Glissez votre image (renommée comme ci-dessus).
4. Bouton vert **Commit changes**.

> Ce fichier `README.md` sert juste à faire exister le dossier. Vous pouvez le
> laisser, il n'apparaît pas sur le site.
