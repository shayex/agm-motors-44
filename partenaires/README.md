# Dossier `partenaires/` — logos des partenaires

Déposez ici les **logos des partenaires**.

- Format conseillé : **PNG à fond transparent**.
- Le nom du fichier doit correspondre au champ `logo:` de la liste des
  partenaires dans `index.html` (repère « ▼▼▼ LES PARTENAIRES ▼▼▼ »).

Noms attendus par défaut :

| Partenaire            | Fichier                       |
|-----------------------|-------------------------------|
| Garage de l'Erdre     | `garage-erdre.png`            |
| Atlantic Performance  | `atlantic-performance.png`    |
| Carrosserie Sèvre     | `carrosserie-sevre.png`       |
| Detailing Nantes      | `detailing-nantes.png`        |
| Pneus Loire Ouest     | `pneus-loire-ouest.png`       |
| Café du Circuit       | `cafe-circuit.png`            |

Si un fichier est absent, les initiales du partenaire s'affichent à la place :
le site n'est jamais cassé.

### Comment déposer un logo ici

1. Ouvrez ce dossier `partenaires` sur GitHub.
2. Bouton **Add file → Upload files**.
3. Glissez votre image (renommée comme ci-dessus).
4. Bouton vert **Commit changes**.

> Ce fichier `README.md` sert juste à faire exister le dossier. Vous pouvez le
> laisser, il n'apparaît pas sur le site.
